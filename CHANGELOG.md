# Changelog

## 0.7.0-rc1 · Hundekraft 3.3 only

- **Requires Hundekraft 3.3** on the original OP-1. The new synth input hook is unavailable in 3.1.4.
- One `ploc.knl` now contains the synth, display, knob mappings and Shift controls. PLOCCTRL is no longer needed.
- The sound engine, screen layout and preset format are unchanged. The install ZIP includes the eight original presets.
- Blackfin build and Mac tests passed. Installation and controls on the OP-1 still need a hardware check.

## 0.6.2 · Hundekraft 3.1.4

- Adjusted the display numbers, QUALITY label and ripple position.
- Uses separate `ploc.knl` (0.6.2) and `plocctrl.knl` (0.6.1) files. The eight original presets are included in its own ZIP.
